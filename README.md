# Terrabit 🐄🐷

**Digitalización aplicada a la ganadería**

Proyecto de innovación desarrollado por el **ITB** en colaboración con el **IES Álvaro Falomir** y la **Asociación de Mujeres del Mundo Rural (DMR)**.

## 📋 Descripción del Proyecto

Terrabit es una solución tecnológica integral diseñada para facilitar la gestión y organización de explotaciones ganaderas, proporcionando herramientas digitales que simplifican las tareas diarias de los ganaderos y dinamizan la actividad de la asociación DMR.

## 🎯 Objetivos

- Facilitar la gestión sobre el terreno de los animales mediante aplicaciones móviles
- Automatizar la interacción con aplicaciones administrativas (GTR, SITRAN)
- Ofrecer servicios de e-commerce para productos de las asociadas de DMR
- Investigar nuevas tecnologías para comunicación e identificación de animales

## 🔧 Ámbitos de Trabajo

### 1. Desarrollo de Aplicaciones
- **Aplicación móvil/webapp** para gestión de animales en campo
- **Plataforma e-commerce** para venta de productos de las asociadas DMR

### 2. Automatización Administrativa
- Integración con **GTR** (Generalitat de Catalunya)
- Integración con **SITRAN** (sistema estatal)
- Generación automática de guías y documentación (DIB)

### 3. Investigación Tecnológica
- Análisis de tecnologías de comunicación para espacios interiores/exteriores
- Sistemas de detección e identificación de animales
- Alternativas tecnológicas a los crotales tradicionales

## 📱 Casos de Uso

### CAS 1: Lectura de Crotales
Lectura de dispositivos identificativos (crotales) en las orejas de los animales mediante aplicación móvil.

### CAS 2: Generación Automática de Guías
A partir de la lectura del crotal, generar automáticamente las guías necesarias cuando los animales salen de la explotación (actualmente proceso manual).

### CAS 3: Plataforma E-commerce
Aplicación de venta de productos y servicios para las asociadas de DMR con gestión de productos, stocks y ventas.
